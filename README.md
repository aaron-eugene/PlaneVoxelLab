# Plane Voxel Lab

Plane Voxel Lab is a personal C++ research and experimentation project focused on voxel terrain representation, surface construction, and real-time rendering.

The project serves as a development lab for investigating different approaches to representing and rendering terrain, particularly techniques that may eventually support editable, voxel-based environments.

## Areas of Exploration

- **Voxel terrain representation:** Organizing terrain into spatially partitioned voxel and chunk structures.
- **Surface construction:** Experimenting with heightmap-derived surfaces, planar patches, and voxel-owned geometry.
- **Real-time rendering:** Visualizing terrain geometry and exploring shading techniques using OpenGL.
- **Editable terrain:** Investigating surface representations that can accommodate local terrain modifications.
- **Large-world coordinates:** Exploring coordinate systems and numerical precision for larger environments.

## Project Structure

The codebase is organized into modules for spatial data, chunks, density fields, geometry, rendering, and experimental implementations.

Individual experiments are developed and evaluated within the lab rather than treated as components of a finished game engine.

## Technologies

- C++
- OpenGL
- GLFW
- GLM

## Project Status

**Active experimental project.**

Plane Voxel Lab is a research-oriented codebase, not a production-ready terrain engine. Its implementation and organization may change as experiments progress.
